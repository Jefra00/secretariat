Intégrez les services Secrétariat Pro directement dans vos applications. Notre API REST renvoie des réponses JSON, supporte l'authentification par token et est disponible en HTTPS.

Authentification

Toutes les requêtes nécessitent un token Bearer

Incluez votre token API dans l'en-tête Authorization de chaque requête :

# En-tête HTTP requis

Authorization: Bearer YOUR_API_TOKEN

# Exemple avec curl

curl -H "Authorization: Bearer YOUR_API_TOKEN" \

https://api.secretariat-pro.com/v1/services/

warning

Ne partagez jamais votre token API. Gardez-le secret et régénérez-le si vous pensez qu'il est compromis.

Endpoints disponibles

category Services

GET /api/v1/services/

Récupère la liste de tous les services disponibles.

// Réponse exemple

{

"count": 12,

"results": [

{ "id": 1, "nom": "Traduction", ... }

]

}

GET /api/v1/services/{id}/

Récupère les détails d'un service par son identifiant.

shopping_bag Commandes

GET /api/v1/commandes/

Récupère la liste des commandes de l'utilisateur authentifié.

POST /api/v1/commandes/

Crée une nouvelle commande. Corps JSON requis.

// Corps de la requête (JSON)

{

"service_id": 3,

"description": "Traduction de 5 pages FR → EN",

"fichier": "base64_encoded_file"

}

GET /api/v1/commandes/{id}/

Récupère les détails d'une commande spécifique.

support_agent Support / Tickets

GET /api/v1/tickets/

Récupère la liste de vos tickets de support.

POST /api/v1/tickets/

Ouvre un nouveau ticket d'assistance.
